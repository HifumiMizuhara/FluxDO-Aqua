> ⚠️ **预发布说明：** 本版本是 Aqua 二次开发分支的预发布版本，不保证稳定性，可能存在 Bug、回归问题或行为变化。

## Highlights / 更新要点

### English

- Added Aqua-specific runtime, rendering, and branding work, including a refreshed preheat experience and an experimental optimized SVG/WebView rendering path.
- Expanded Japanese, Korean, and Traditional Chinese localization coverage with locale-aware CJK typography improvements.
- Improved private messages with recipient grouping, category refinements, real-time updates, and safer staged-message fallbacks.
- Hardened Android stability and memory behavior, including crash mitigation, image-heavy route handling, and safer native view transitions. Aqua Lab's crash mitigation is enabled by default for new installations.
- Improved network and content reliability with safer Cloudflare WebView handoff, redirect option preservation, stale-result filtering, account-level ignored-user filtering, and safer download paths.
- Disabled the upstream Crashlytics/Firebase release dependency for this secondary-development distribution and added an independent Android release-signing setup.

### 中文

- 加入 Aqua 专属的运行时、渲染和品牌体验改进，包括全新的预热界面，以及实验性的 SVG/WebView 优化渲染路径。
- 扩充日语、韩语和繁体中文本地化覆盖，并改进按地区适配的中日韩字体排版。
- 改进私信功能：支持按收件人分组、优化分类、实时更新，并增强暂存消息回退逻辑的安全性。
- 加强 Android 稳定性与内存处理，包括崩溃缓解、图片密集页面处理和原生视图切换保护。Aqua Lab 的「崩溃缓解」对新安装默认开启。
- 提升网络和内容可靠性：改进 Cloudflare WebView 交接、保留重定向请求选项、过滤过期结果、支持账户级忽略用户，并增强下载路径安全性。
- 针对二次开发发行版移除上游 Crashlytics/Firebase 发版依赖，并加入独立的 Android Release 签名配置。
